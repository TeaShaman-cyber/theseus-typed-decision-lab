# Experiments

Every durable experiment starts from or links to a GitHub Issue.

Bootstrap sequence:

1. repository/QA bootstrap under issue #1;
2. SemIf CPU runtime feasibility canary;
3. canonical contract projection after Needle #55 versions it;
4. shared cross-model benchmark under the research line in Needle #56.

Heavy experiments must record exact source/model revisions, realized runtime,
fixture identity/hash, outputs, and claim scope.
